HCR-3A / Rodi: Tool I/O 그리퍼 방향 확인 테스트

2026-10-06 갱신: 사용자가 출력0=열기, 출력1=닫기를 확인했습니다.
아래는 확인 전 작성한 초기 테스트 기록입니다. 최종 전환/Reverse 설정은
docs/hcr3a/03_RODI_GRIPPER.md와 펜던트 실제 프로그램을 참고하세요.

이 파일은 펜던트에 입력할 명령 순서입니다.
Rodi에서 가져오기/실행 가능한 네이티브 프로그램 파일이나 스크립트가 아닙니다.
로봇 팔 이동 없이 출력 0과 출력 1의 동작 방향을 각각 확인합니다.
채널 번호 0/1과 출력 값 LOW/HIGH를 구분하세요.
OPEN/CLOSE 매핑 및 LOW 시 동작은 아직 확인되지 않았습니다.

준비
- 기존 sorting 메인 프로그램 및 다른 출력 제어 쓰레드를 정지합니다.
- 그리퍼에 물체를 물리지 않고 손을 빼고 테스트합니다.
- Tool Power 설정은 기존 설정을 유지합니다. 이 프로그램은 전압을 변경하지 않습니다.
- 새 메인 프로그램을 두 개 만듭니다. 반복 실행은 사용하지 않습니다.
- SET > I/O > Tool I/O에서 설정합니다. MODBUS나 SET Var를 사용하지 않습니다.
- 각 SET에서 사용할 출력만 선택하고 LOW/HIGH를 지정합니다.
- Reverse는 해제합니다. 아래 명시된 SET LOW가 출력을 끕니다.
- WAIT는 시간 대기이며 단위는 초입니다.
- 아래 0은 LOW/OFF, 1은 HIGH/ON을 뜻합니다.

프로그램 1: GRIP_TEST_0
01 SET I/O: D_TOOL_OUT_0 = LOW
02 SET I/O: D_TOOL_OUT_1 = LOW
03 WAIT: 1.0초
04 SET I/O: D_TOOL_OUT_0 = HIGH
05 WAIT: 1.0초
06 SET I/O: D_TOOL_OUT_0 = LOW
07 WAIT: 1.0초
프로그램 끝 (LOOP 없음)

프로그램 2: GRIP_TEST_1
01 SET I/O: D_TOOL_OUT_0 = LOW
02 SET I/O: D_TOOL_OUT_1 = LOW
03 WAIT: 1.0초
04 SET I/O: D_TOOL_OUT_1 = HIGH
05 WAIT: 1.0초
06 SET I/O: D_TOOL_OUT_1 = LOW
07 WAIT: 1.0초
프로그램 끝 (LOOP 없음)

관찰
GRIP_TEST_0 HIGH 동안: 열림 / 닫힘 / 변화 없음
GRIP_TEST_0 LOW 복귀 후: 유지 / 반대로 움직임 / 기타
GRIP_TEST_1 HIGH 동안: 열림 / 닫힘 / 변화 없음
GRIP_TEST_1 LOW 복귀 후: 유지 / 반대로 움직임 / 기타

0 HIGH=열림, 1 HIGH=닫힘이면 OPEN 채널=0 / CLOSE 채널=1.
0 HIGH=닫힘, 1 HIGH=열림이면 OPEN 채널=1 / CLOSE 채널=0.
변화가 없거나 예상 밖이면 매핑을 확정하지 않습니다.
두 출력 HIGH 동시 활성화는 이 테스트에 포함하지 않습니다.
프로그램 정지가 마지막 LOW 명령 실행을 보장하지 않습니다.
중간에 정지했다면 다시 시작하기 전 펜던트에서 두 출력 LOW를 확인합니다.
이 테스트의 LOW는 무명령 출력 상태이며 기계적 정지/힘 해제를 보장하지 않습니다.

실행
PC 서버/카메라/더미 관제는 필요 없습니다. 펜던트에서 직접 실행합니다.
프로그램 1을 한 번 실행하고 결과를 관찰한 뒤 프로그램 2를 한 번 실행합니다.
확인 전에는 기존 PICK/PLACE 프로그램에 결합하지 않습니다.
