# Third-party dependencies

LeRobot: https://github.com/huggingface/lerobot (Apache-2.0).
Pinned source commit: 8fff0fde7c79f23a93d845d1a50e985de01f8b8a.
Installed by pip; LeRobot source is not vendored here.
Other dependencies retain their own licenses. The setup script installs packages from PyPI and the official PyTorch CPU wheel index.

The OMX pair profile contains the six-motor calibration records from the current project equipment. These are device configuration values, not a general calibration for all OMX arms. The collector validates them against the connected hardware without writing calibration.
